# Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in AFFT-Toolkit, please report it privately before disclosing it publicly.

**Do not** open a public GitHub issue for security vulnerabilities.

### How to Report

- **Email**: soe1hom-arch@users.noreply.github.com
- **GitHub**: Use the [Security Advisory](https://github.com/soe1hom-arch/AFFT-Toolkit/security/advisories/new) feature

We aim to respond within **48 hours** and will work with you to address the issue promptly.

## Scope

This security policy applies to the AFFT-Toolkit application and its source code. Third-party binaries included in the project are subject to their respective security policies.
